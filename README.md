# Gereja Katolik Web

Fondasi website paroki dengan Nuxt 4, TypeScript, Tailwind CSS v4, dan deployment target Vercel.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run build
```

## Architecture

See `ARCHITECTURE.md`.

## Deployment

Push repository ke GitHub lalu import repository tersebut ke Vercel. Vercel akan mendeteksi Nuxt secara otomatis.
